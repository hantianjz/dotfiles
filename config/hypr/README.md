# Hyprland keybindings

Active Hyprland/Omarchy shortcuts for this machine. Generated from `omarchy menu keybindings --print`, so it reflects the live compositor registry, including user overrides in this folder.

## Notes

- `SUPER` is the Super/Windows/Command key.
- Duplicate shortcuts are expected when Hyprland registers multiple actions for one combo, for example `ALT + TAB` focus plus reveal.
- `XF86...` entries are hardware/media keys from the keyboard firmware.
- Managed source files live in `~/.dotfiles/config/hypr`; `~/.config/hypr/*.lua` are symlinks into this folder.
